# 墓穴机关图像、形状与声音

固定原版 `7d9246600fffe518408f5830d4848635019005a3` 的 14 个机关新增独立 `ENCDMP01` 候选，格式与能力均为 1、7356 字节。包含四种精灵、原始节点顺序、父层排序、17 个矩形与已有 `ENCDMA01` 时钟绑定。共享核心生成绘图矩形与碰撞几何；不创建地图、GPU 纹理、物理世界或存档，也没有提前开放墓穴入口。

拉杆、踏板、普通门与墙门分别保留 2、2、6、15 帧。门的精灵偏移是 `(0,-8)`；墙门本体位于 `(-648,120)`，镜头目标另加 `(0,44)`，不能把后者当作碰撞或绘图原点。`Objects` 父 TileMap 开启 Y 排序，`Bottom2` 未开启。拉杆碰撞体的小数偏移按原版保留身体、形状各自的 binary32 平移，再按原生全局变换顺序组合。

图像来源及许可在 `content/catacombs-mechanism-graphics.json`；原始 PNG 未裁边、重画或缩放。实际 tex3ds 2.3.0 生成四份候选纹理，共 1,183,828 字节。原引擎两次实际导入一致：可见像素和 alpha 完全保持原样，导入器的透明边缘修复仅改变 alpha 为零的 RGB。移植保留原 PNG RGBA，使用原版的最近邻、无重复、无 mipmap 策略；不据此宣称屏幕像素完全一致。共享加载器核对纹理字节数和 CRC，SHA 留作来源身份，尚无正式 GPU 绘制验收。

`content/catacombs-mechanism-presentation.json` 记录源形状选择、实际纹理身份和已观察的引擎默认值。碰撞层、掩码、监视、单向标志、安全边距和原信号连接均被检查；不接受未审查的子节点覆盖、变换、材质或形状。未知格式、能力、记录、来源、别名、非有限值和越界全部拒绝，失败不提交部分对象。

`content/catacombs-mechanism-audio.json` 经现有音频转换器生成四种原音效：拉杆、踏板关门、石墙移动和操作受限提示，共 409,260 字节 PCM。六个真实 `AudioStreamPlayer` 的归属分别记录，操作受限声保留 `audioManager` 的 `switch` 通道。现有 bump 资源完全复用原身份、路径及 48 kHz 转换；墙门保留已审查身份 90211837。其余身份属于移植资源，不是原版 ID。候选音频库与正式 BGM 分开；实际播放、节点重启／停止和离场回收仍待接线，不能据候选 PCM 宣称已经听到声音。
