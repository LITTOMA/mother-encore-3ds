# 缺陷与后续验证

本页归类已定位问题及仍需验证的范围。功能支持以 [STATUS](STATUS.md) 为准，开发顺序见 [DEVELOPMENT_PLAN](DEVELOPMENT_PLAN.md)；过去的实验或局部测量不自动代表当前构建。

## 已修复或已解释

| 问题 | 结论与处理 |
|---|---|
| 画布与房屋墙面出现不同黑色 | 游戏清屏色从受检 project.godot 读取 RGB(28,28,28)，保持素材、淡出和参考模式黑色独立；见 [加载实现](LOADING_PERFORMANCE.md) |
| 卧室底边看似越界 | 原碰撞接触位置正常；漏绘的 276 个 Above 前景 tile 已恢复，不增加位置 clamp 或假障碍 |
| Lamp 战后周期震动 | 属于原版 RoomShaker 行为；按 Doll attack 最后一段停止，不能作为显示缺陷随意删除 |
| Minnie 离开房间时露出有限前景遮罩 | 保留原版无碰撞剧情路径；补齐对话拥有的 Blackbars 层，见 [NPC 遮挡](NPC_DOORWAY_OCCLUSION.md) |
| 上层右侧房门与跑步教学关系不清 | Pillow / Minnie 与 Mom-room 门路线已连接，是可选支线，不是 Doll 旋律主线的前置；见 [支线范围](PILLOW_MINNIE.md) |
| 正常标题进入命名时的纹理加载失败 | 在命名前释放标题 GPU 纹理，失败 / 取消后重建标题；见 [纹理生命周期修复](NEW_GAME_TITLE_TEXTURE_FIX.md) |
| 命名时 START 导致全局退出 | START 不再全局退出，正常退出使用标题 Exit |

上述处理不代表每项在当前源码与每款硬件上重新验收。回归时记录对应提交、实际产物和重现入口。

## 未完成或待验收

- 严格程序 / 数据分离的完整迁移，避免真实内容和绑定留在 C++。
- 完整 Introduction、Podunk 与后续场景，以及其所需的原版机制。
- 通用物品使用与其余战斗、队伍和菜单机制；已支持的局部范围见 STATUS。
- 加载、背景渲染与场景切换的当前构建性能和内存测量；局部内核数据不代表全游戏帧率。
- 音频实际可听性，Old / New 3DS 上的安装、输入、休眠恢复及存档验收。

报告新问题应附源码提交、配置、平台、最短重现步骤与必要日志，并移除私人信息。验证方式见 [TESTING](TESTING.md)。
