# 喷口实例的玩家接触与退出

这个候选将已审查的喷口实例、实际玩家碰撞形状和角色伤害消费者连接起来。原喷口在动画开启monitoring后才能接触，玩家暂停进入会消费事件，恢复后必须离开再进入；关闭monitoring或删除喷口会发送退出，停止持续伤害，保留已加状态。正式墓穴场景尚未接入，不扩大当前游戏可玩范围。

复用独立的玩家接触、喷口家族、伤害和脚步资源，没有新增资源格式，也不修改目录capability、规则兼容或游戏存档。源内容来自固定原作 `7d9246600fffe518408f5830d4848635019005a3`；C++只含受检绑定、采样和执行，没有地图坐标或伤害调参表。源矩形的extents、旋转与局部原点来自喷口资源，实例位置来自实际工厂请求；工厂已覆盖场景预置的root位置，不能再次加上预置偏移。

共享核心绑定实际注册表地址、资源拥有者、场景代次、Ready实例票据和玩家身份。每次物理处理前发布前一轮接触，移动后用原矩形与八顶点身体作包含边界的凸SAT查询。仅支持同一父坐标空间中的平移；任意父变换、原物理边距、跨实例宽相位顺序和自然移动并未因此实现。Party、未知身体、错误来源、未Ready或失效实例均明确拒绝。

移除前必须完成接触采样、发布尚未消费的转换，并交付该实例的待执行回调和声音命令；失败保留角色、接触与输出。随后在拥有者确认的移除边界交付原退出，再注销实例。拥有者须先验证完整的场景事务；这个单实例服务不代替正式场景的全体对象清理协调。

## 实际对照

最终两次实际Godot 3.6.2运行各72个稳定状态，结果SHA均为 `21ea5db0fe493f5c265a1c24cbc197350a04df9be9f61819459c6690ef144e05`。使用完整原喷口脚本／场景、真实Area2D与旋转矩形、实际KinematicBody2D及原玩家形状、完整Character／Status和选定Player受伤／Flash方法；四个MP3、原PNG与喷口导入参数仅用于私有对照项目，未复制进报告或新增游戏资源。

八个案例覆盖普通进入／停留／离开／再入、暂停进入、Other身体、禁用形状再启用、零过滤、动画关闭monitoring、暂停退出，以及动画完成删除。原引擎确认两种移除边界不同：普通显式queue_free在真正移除时退出；动画完成会先关闭monitoring，退出已发生在删除队列清空前。两种都会停止持续伤害。

动画时钟、瞬移和普通移除是明确的测试服务，玩家暂停服务从声明信号的基类实际发射信号；UI／图形／声音消费者的范围单独限定。没有运行完整Player运动、37个工厂的同时物理世界或正式墓穴。C++对照普通移除案例时，由测试拥有者调用接触退出和注册表移除，不把原queued位当作一个凭空构造的注册表queued位；动画完成案例还比较实际注册表queued状态。原始72状态全部保留，声明范围的接触、HP、状态、RNG、几何和动画字段逐项比较，未改写原期望。
