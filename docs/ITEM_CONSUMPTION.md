# 原版普通菜单消费候选

Hamburger、Fries、Antidote及既有AsthmaSpray的消费共享核心候选已加入。HP按原版恢复并钳制上限，满血仍消费并报告回满；状态药按实际命中或失败显示对应消息，失败也扣剂量。原Item在最后一次使用时由库存移除，但仍被引用的原对象剂量保持1；多剂量喷雾只在保留实例时减1。解除状态时原PartyMember还会在HP为零且没有昏迷时尝试设置HP为999并钳制，这个源参数保留在独立资源中，没有在C++硬编码。

消费规则、消息、角色、已审查状态域、原食用音效路径／slot及平台Effect通道绑定追加在独立ENCFMN01 v3中；v2读取保留，旧包字节不变。执行仅支持已审查的单角色、HP食物、单状态药、非复用／非变形／非属性提升道具。未知状态、角色、控制符、能力、缺失／重复效果、无主消息和非法通道均明确拒绝。所有已声明消费动作须有效果绑定，不能缺资源时降为无效果扣道具。
