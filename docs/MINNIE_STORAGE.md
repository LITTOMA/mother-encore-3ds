# Minnie 仓库流程

固定来源为 Mother: Encore `7d9246600fffe518408f5830d4848635019005a3`。玩偶胜利、`doll_melody` 生效后，Minnie 的原版对话选择可打开普通仓库；取消和关闭仓库均返回原版告别短语与剧情回调。

## 本次接入

背包与仓库之间转移 BaseballCap 和已领取的 AsthmaSpray，保留物品 UID、剂量及取得标记。存放已装备帽子先询问卸下；取出帽子先转移，再询问装备，拒绝装备仍保留取出的物品。装备变化同步更新七项角色属性，HP / PP 上限变化按来源规则处理。仓库容量、排序、装备属性、双语提示、声音、布局与光标时序均来自受检二进制，不写在执行代码中。

3DS 使用原版纹理、EBMain 正文及 BottleRocket 描边计数字体，列表、确认提示与人物状态指示均按 1:1 图素绘制，默认居中适配 400×240。首次打开时在 GPU 帧外准备纹理与字体；关闭后复用已准备资源。

Record 捕获实际背包和仓库；LOAD 在独立候选状态中验证并准备库存、装备及派生属性，成功后整体提交。跨两处库存检查 UID 唯一性、原始帽子守恒和喷雾取得策略；未知物品和无效装备明确拒绝。仓库存取不创建新 UID，不消耗随机流。

## 资源与兼容

- `native-storage.json` / `storage-assets.json` 保存来源 IR 与转换配方；`native_storage.py` 生成 `data/opening.encstorage`（ENCSTG01，格式 / 能力 / 规则 1）。纹理按类型放在 `graphics/ui/storage`，菜单声音放在 `sound/effects`。JSON 与审查记录不进入 RomFS。
- Room 增加独立能力 8 的 OpenStorage 指令，与紧邻 AwaitSubmenu 形成受检回调边界；游戏规则仍为 7，旧能力 4–7 保持各自指令限制。
- Session 资源 v5 加入来源派生的库存守恒与装备策略；存档编码格式及稳定物品身份不变，旧 Session 资源仍按原有受限范围加载。
- 加载器检查版本、CRC、目录、UTF-8、有限数值、引用、路径、来源 pin 与 Items 身份；资源生成和打包也检查来源及产物指纹。

## 验收边界

这是当前房屋内普通仓库的局部可用流程，不代表全游戏物品系统完成。尚未支持其他队员、其他物品、神模式仓库、富文本喷雾描述或物品使用。滚动上下旋转箭头、角色栏底图和询问文字高亮装饰尚未绘制；翻页、滚动条、人物状态、确认光标及存取操作已接入。

相关正常和负向用例已加入手动全面测试入口，本次未运行测试套件或 sanitizer。真实 3DSX / CIA 构建与资源提取检查以对应候选 Actions 为准；模拟器、Old / New 3DS 的显示、声音、操作及存档验收仍未执行。
