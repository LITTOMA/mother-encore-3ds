# 地图初始化的随机结果

本次抽出离线初始化重放并保留闪光帧的随机结果，尚未将它接入正式场景对象资源。运行时没有新增随机流，Mick的版本、完整IR、已编码二进制和294条视口事件保持逐字不变。

原Mick生成器先按场景树的子节点优先顺序重放草丛、鸟、蝴蝶和闪光的_ready调用，然后将结束PCG状态存入Mick初始化数据。其后的视口事件只有蝴蝶、敌人生成器和NPC漫步；闪光不在其中。先前取铲记录把这两部分混淆，现已更正。直接在运行时再执行闪光rand_range会重复抽取，改变后续状态。

field_ready_rng保留既有调用顺序、草丛名称的seed、randf单精度及全局rand_range的双精度语义；未知来源脚本、未映射随机调用、坏树关系和未知参数均拒绝。来源树产生3506次操作及22个闪光样本，结束状态为621950984495336987；铲子Sparkles在3186号操作取得6.629633243201263，原版截断为帧6。它发生在草丛seed之后，不依赖未记录的入场随机状态。

Godot3.6.2实际执行了此来源序列的全局内建调用，所有3506个数值及每一步PCG状态均与新计算器一致；最后的randi哨兵也一致。该探针不加载完整游戏场景，不证明未移植脚本或所有随机时机。二进制数值记录、原始脚本和来源保留在reports/iggy-tutorial/ready-rng-reference-1。

原Mick二进制SHA仍为a7c50629baf53e2fb303ea5bc9f5cff4dd4eaa2a01f8583227640e6b36301e2c。原生成器只更新了已核对生成凭据的producer指纹，原凭据字节备份保留，纹理、IR及pack完全不变；预先存在的四个未跟踪目录没有加入Git或删除。七项新Python、十六项Mick／NPC旧检查及374项资源核对通过。这里没有使用模拟器或真机，也没有宣称新的可游玩范围。
