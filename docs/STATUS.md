# 当前状态

Mother: Encore 的局部原生 Nintendo 3DS 移植。共享 C++17 核心运行受检内容，3DS 后端负责渲染、输入、音频和存储；不运行 Godot 或通用 GDScript 解释器。完整游戏尚未完成。

固定上游为 Act2 v0.4.1.0，提交 `7d9246600fffe518408f5830d4848635019005a3`。上游以只读子模块引入，完整清单覆盖 5,839 个文件。来源固定不等于全量行为兼容。

| 世界 | 开局房屋内的移动、碰撞、人物动画、房门切换、七种物件调查、床头抽屉领取喷雾及四个礼物盒绘制（Present4 可领取狗粮、Present3 可领取地图并保存物件状态）；房屋正门经原版 Circle Focus 转场进入 Podunk 室外（完整 TileMap 图层与碰撞、草丛空闲帧、静态物件、可开启门）并可返回房屋；院子 Mick 会漫步、按旗标说已审查的 woof 树，给粮前南栅栏 `mick_bark` 把玩家往北推回 |

| 菜单与存档 | 局部 Items 菜单、自由行走 START → Pause / PSI / Equip、开局心灵感应与装卸属性预览、Minnie 普通仓库存取与装备确认、Dad Record、受限 Continue / LOAD；只接受已支持的房屋、进度和格式 |
| 语言 | 英文 `en` 与简体中文 `zh_Hans_CN`；其他语言尚未开放 |
| 音频 | 房屋门、对白语音、电话、Mick、战斗菜单与命中、胜利和升级音乐已接入；Podunk 的 13 个原版音乐区域使用受检几何和区域控制器；实际可听性未验收 |

LOAD 对未知场景、版本和身份明确拒绝。精确 rules6 历史身份仅通过受检的只读兼容路径接受；它不是任意 Godot 存档转换器。M0 沙盒仅用于隔离机制测试，其 fixture 战斗不能代表原版玩法。

Introduction 使用独立 `.encintro`，11 张原版纹理、专用受检字幕字体与原版开场音频。自然播放与原版跳过分别受测；历史动画的 116.5 秒键保留来源记录，因原作长度 116 秒而不触发。房屋建立于门口换场点，玩家按原作淡入信号解锁。

床头抽屉使用独立 `.encdrawer`：完整保留原版调查、已领取、背包满和领取分支；领取前检查容量，物品先入背包，再显示文字、播放原版提示音及设置标记，随后等待确认。喷雾保留三次剂量、原版名称与图标，Record／LOAD 保留物品 UID 和领取标记。Items 二进制 capability2 保留原始描述和未实现的使用动作；独立 `.encdetails` 将已支持的帽子与喷雾描述接入 Items / Minnie 仓库，包含实际昵称、哮喘图标、剂量及属性值。其他物品与使用动作仍明确禁用；Session 资源 v4 增加来源派生的获取策略，存档编码及旧默认值保持原有兼容边界。

Introduction 的音乐、文字音和动画音效在动画开始前一次性校验 PCM，已准备流不重复校验；音频仍使用有界流式缓冲，不改变播放时间或随机数。读取耗时及设备表现尚未验收。

房屋准备阶段也收集受检 Room 音源、House 对白语音、Phone 铃声 / 接听声、选择及 Record 菜单声音和对白反馈音效，进入交互前校验 PCM；通话时复用已准备流，避免第一次播放触发临时加载提示。Phone 请求只走专用播放队列，保留原版动画声音键及同一播放器的替换 / 重启，取消普通世界音效队列中的重复请求。此改动未建立原版空间衰减或 SaveSelect 音乐滤波的等价性，设备可听性仍待验收。

Minnie 在玩偶胜利后的原版 Storage 选择已接入双栏仓库：帽子和已领取喷雾转移保留 UID，装备确认同步角色属性，Record／LOAD 保留实际仓库。独立 `.encstorage` 承载规则与布局；Room 能力 8 增加受检子菜单回调而保持游戏规则 7，Session v5 支持库存守恒和装备派生属性。已支持的帽子与喷雾富文本描述已接入；物品使用与少量装饰仍未完成，详见 [Minnie 仓库](MINNIE_STORAGE.md)。

房屋和 Podunk 室外自由行走时按 START 打开原版六项 Pause 菜单；本切片开放 Equip 和开局野外 PSI：Ninten 2 级的心灵感应，详见 [野外 PSI](FIELD_PSI.md)。正常新游戏的完整五人角色资料按实际单人 party 选择 Ninten，旧单人 LOAD 资料仍接受。四个原版装备槽使用实际背包 UID，帽子 / None 选择显示七项属性预览，确认才提交库存与派生属性；Record / LOAD 沿用现有装备身份，场景仍限受支持房屋。来源、限制与设备验收步骤见 [野外装备菜单](FIELD_EQUIPMENT.md)。

Pause / Equip 背景绘制保留来源 StyleBox 的扩展量，Pause 标题底板按实际文字宽度绘制，修正宽白边与标题遮挡；布局由受检资源承载，绘制能力升为 2，规则 / 存档不变，设备显示仍待验收。见 [野外装备菜单](FIELD_EQUIPMENT.md)。

具体范围见 [启动设置](STARTUP_SETTINGS_CHECKPOINT.md)、[多语言运行时](MULTILINGUAL_RUNTIME.md)、[Continue / LOAD](CONTINUE_LOAD.md) 和 [战斗资源驻留](BATTLE_RESIDENCY_CHECKPOINT.md) 和 [房屋后续调查与对话](HOUSE_FOLLOWUP.md)。

Doll 的正常战斗画面已接入受检纹理后端：GPU 直接采样两层径向背景并重建有限调色板混合，不生成整帧 CPU 颜色图。后续性能修复将来源图像的旋转同色区域证明接入纹理消费者，直接输出两层原始索引区段，取消该路径的逐条带递归证书和 576 KB 残差表；帧常量及代表采样坐标预先缓存，统计按行汇总。下屏显示 `GPU index runs`、实际绘制区段、次数、CPU 准备 / 提交耗时和采样数。原始缩放、时间、调色板及边界精确后备保持原有行为，Pillow 路径沿用既有后端。真实 Doll 资源的私有主机计量已见 CPU 耗时下降；新构建的模拟器帧率和真机表现尚未验收，见 [战斗资源驻留](BATTLE_RESIDENCY_CHECKPOINT.md)。

Podunk 室外由 `world/podunk/podunk.encmap`、`world/podunk/podunk.encroom` 与 `world/world.enclinks` 承载，构建时直接从固定上游场景编译；资源目录升至能力 5（含 HousePresents、MickTreats 和完整音频绑定）。Mick（npc21）会在院子里漫步，并用已审查的 woof 树与南栅栏 `mick_bark` 推回完成给粮出图；走到他身边且事件射线碰到他时，显示与房屋 NPC 相同的静态按键提示。台词画在上屏原版对话框里，并使用标题画面选中的英文或简体中文（见 [Mick](MICK_TREATS.md)）。进场随机数账本已按 400×240 视口消耗草丛、鸟、蝴蝶、闪光和其它漫步 NPC 的首次抽取，但敌人不生成、其它 NPC 不走路。其余 NPC 对话、过场区域、建筑入口和物件交互仍为开发边界或下屏提示。门音效和 13 个音乐区域已接线，来源、边界和验证记录见 [音频补全](AUDIO_COMPLETION.md)。模拟器与真机均未验证，详见 [Podunk 室外场景](PODUNK_FIELD.md)。

开局 BGM 中断修正：房间震动雷声的 Room ID 与音频库 ID 不同，旧消费者误判来源并阻断后续音乐请求，同时跳过已有流的补给。现在按来源路径和 SHA 精确匹配，错误请求仍报告并保留，但已有 BGM 继续更新；资源与剧情时序不变。新增回归用例未执行，设备听感尚未验收，详见 [音频补全](AUDIO_COMPLETION.md)。
