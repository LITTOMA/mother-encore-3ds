# 房屋战后调查与家人后续对话

固定来源：Mother: Encore `7d9246600fffe518408f5830d4848635019005a3`。本切片从现有正常房屋入口接入，保留既有开场、战斗、电话和保存身份。

## 可玩范围

- 调查公告板、老照片、电吉他、NES、楼上电视、楼下电视和 Mimmie 的玩具箱，使用原版文本及英文／简体中文绑定。
- 保留调查区域的继承碰撞、实例缩放、玩家朝向约束、提示偏移和有序旗标覆盖。闹鬼阶段使用原版“现在不是时候”对话；玩偶胜利后的调查文本按原版覆盖顺序选择。
- 爸爸电话后的 Carol 和 Mimmie 钥匙提示，以及设置询问旗标之后的再次对话。旗标写入由已受检 Room 程序执行；不是把带副作用的 YAML 当成纯文本。
- 调查与 NPC、电话、门共用最近射线目标选择。未支持的最近对象仍遮挡后面的对象。调查没有原版阅读身份写入，不制造 NPC 已读记录。

## 数据与消费者

`content/native-house-inspections.json` 为来源 IR；`tools/house_inspection.py` 编译 `data/opening.encinspect`（ENCHIN01）。该资源只持有调查几何、绑定和条件，文本由追加链接进入既有 `.enchouse`，不重复字体或图像。

HouseInspectionData 检查版本、能力、目录边界、校验和、身份、引用及数值。HouseRuntime 绑定时检查来源、旗标注册和 House 对话索引／路径；普通启动、New Game 和 LOAD 都绑定同一资源。3DS 从受检资源目录加载该二进制，不读取 JSON。提示格式能力 2 增加调查对象，继续接受已有能力 1 的解析路径；存档格式、游戏规则和既有稳定身份保持不变。

## 明确边界

床头抽屉的默认／战后程序需要背包检查与哮喘喷雾赠予，仍明确阻断；其闹鬼阶段普通对话已接入。Minnie 的储物选择需要实际仓库消费者，仍不支持。非空调查出现／消失旗标涉及原版 Ready 和 flags_updated 删除顺序，本格式绑定明确拒绝。Podunk 和全游戏物品／菜单未因此完成。
