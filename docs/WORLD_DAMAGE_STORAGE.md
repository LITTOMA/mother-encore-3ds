# 世界伤害更新保持角色存储归属

世界伤害原先在提交候选状态时移动替换整个 `SessionCharacter`。即使一次调用没有改变角色内容，也会重新分配背包、已学技能、属性修正及身份字符串的存储，使调用者持有的引用失效。自动毒区接触组合测试在第一次实际扣血后发现背包指针变化，随后独立回归确认五个入口均受影响。

修复保留原事务计算，只提交这些原方法实际修改的HP和状态；状态仅在原事件批次包含 `StatusChanged` 时替换。重复添加状态、删除不存在的状态、暂停／无敌中的物理尾段以及其他无操作分支保留已有状态存储。拒绝调用继续保留全部调用者与随机数状态。

受影响入口为 `add_status`、`remove_status`、`begin_continuous`、`damage` 和 `physics_tail`。固定原作仍为 `7d9246600fffe518408f5830d4848635019005a3`，所用PartyObject／Player、Character／Status方法和伤害规则见[世界伤害](WORLD_DAMAGE.md)。没有修改原版HP／状态／事件顺序／RNG、资源、生成器、格式、规则兼容或存档编码，也没有扩张可玩范围。

独立回归逐次检查身份／昵称字符串、背包及道具字符串、技能数组及技能字符串、永久修正和亲和修正的八组地址及原值；另检查重复状态等无操作路径的状态存储。修复前21,368项中22项失败，修复后相同检查全部通过；原有361条原引擎观察没有更换或重写。初次修复在已授权主线基础检查，随后整合已通过完整检查的#95，再次通过21,368项。

三次检查实际使用GCC ASan＋UBSan及正常泄漏检查，重新编译受影响世界伤害模块并链接逐文件核验未变的117模块归档，不是完整核心重编译。输入指纹、原始失败／成功日志与依赖整合证明在 `reports/world-damage-storage`。没有新的原引擎、模拟器或硬件运行。
