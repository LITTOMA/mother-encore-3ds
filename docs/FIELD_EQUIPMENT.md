# 自由行走 Pause / Equip

固定来源：Mother: Encore `7d9246600fffe518408f5830d4848635019005a3`，原版 Pausemenu、EquipMenuUI、Inventory、PartyMember 与相关场景、纹理、字体和翻译。

在房屋或 Podunk 室外自由行走、没有对话、剧情或战斗接管输入时，按 START 打开六项 Pause 菜单，方向键或摇杆选择 Equip，A 确认。四槽保留原版顺序；当前 BaseballCap 和已领取的 BatPlastic 有合适装备槽。已装备时选择 None 可以卸下，卸下后选择同一背包实例可以重新装备。B 从候选返回槽列表，再返回 Pause，最后关闭恢复行走。PSI 包含当前开局心灵感应和日记习得的 Lifeup α；六项命令及当前子菜单见 [START 菜单](FIELD_MENUS.md)。

当前 `ENCFIE01` 格式仍为 v2，能力为 5；新增菜单内容由独立 `ENCFMN01` 承载。下面保留此前装备与 PSI 扩展的来源和格式演进记录，最新验证层次以 [START 菜单](FIELD_MENUS.md) 为准。

属性预览来自当前属性减去该槽旧装备增益，再加入候选增益；同时与既有 Session 来源派生属性核对。预览与取消不改变库存；确认在独立候选状态完成身份、库存守恒、装备、七项属性及会话检查后才提交。UID 0 与 None 分开表示，装卸不创建物品、不减少剂量、不调用随机数。Record 捕获实际装备，LOAD 沿用当前身份和存档格式。

正常 New Game 保留完整五人启动角色资料，当前 party 仍为单人 Ninten；菜单按受检 party 身份查找实际队员，不再把资料库人数当作队伍人数。旧单人资料仍接受，缺少 / 重复的当前队员或未支持队伍明确拒绝。装备读取、预览和提交沿用原版 UID、槽位、增益与 Session 检查，不修改非当前队员资料。

Podunk 菜单使用当前室外 World 的暂停 / 恢复、输入门限、遮幅及绘制入口；对话、剧情、战斗、换场和其它菜单期间不能抢夺输入。装备校验读取当前场景旗标，避免 Mick 给粮后的钥匙物品状态与停放房屋的旧旗标混用；位置 / 场景身份仍是实际保留的房屋投影，仅用于既有 Session 校验，不提供室外 Record / LOAD。打开失败显示具体原因并恢复同一场景的玩家。

## 资源与显示

`ENCFIE01` v2 独立受检二进制包含来源派生的数字 OwnerId、角色名称绑定、六项命令、四槽、装备增益、布局、纹理指纹、动画及平台输入映射。数字 OwnerId 与 Items metadata.owner 比较，角色名称另与实际 Session 核对；数字 ID 不作为字符串表偏移。旧 v1 与未知版本明确拒绝，能力、规则和存档版本保持原值。普通资源编译核对受检来源；加载校验版本、能力、UTF-8、CRC、目录、有限数值、路径、引用与 Items 身份，失败保留已加载内容。13 张原版小纹理放在 `graphics/ui/equipment`，两个新增 Pause 音效放在 `sound/effects`；配方、IR 和来源收据留在构建输入目录。

菜单采用 EBMain 与 BottleRocket 原版字体、源动画及光标时序，图素保持 1:1，默认居中适配 400×240。首次打开在 GPU 帧外准备小纹理、计数字体和声音，之后复用；不会重建已结束的 Introduction 图集。菜单暂停当前场景的玩家，音乐与游戏时间继续推进。


菜单绘制修正（2026-10-14）：原消费者把 StyleBoxTexture 的控件矩形直接当作绘制矩形，漏掉 `expand_margin_*`。Pause 外框应从 `(7,7,156,66)` 扩为 `(4,4,159,72)`，内背景从 `(15,15,140,50)` 扩为 `(4,4,159,63)`；命令文字仍保留原位置，因而恢复正确的内边距。Equip 属性背景也按来源扩展，外框改回原场景引用的 `defaultempty`。扩展仅影响背景绘制，不改变控件内容或输入位置；语义见 [Godot 3.6 StyleBoxTexture](https://docs.godotengine.org/en/3.6/classes/class_styleboxtexture.html)。

Pause 标题的原版深色 ColorRect 以新的独立布局角色保存，平台按受检字体的实际标题宽度加上来源边距绘制底板，再绘制文字。既有布局和素材身份保留，ENCFIE01 仍为 v2，绘制 capability 升为 2；旧 capability1 和未知值明确拒绝，游戏规则和存档格式不变。源矩形、扩展、颜色、贴图引用及底板尺寸均由原生成器编译，C++ 不内嵌内容调参。

纹理收据通过原生成器的 `reuse-assets --base` 路径更新：要求精确基线提交、旧 IR / producer 指纹匹配、原有全部来源 SHA 和纹理配方完全相同（可增加经过 IR 重建校验的逻辑来源）、`compile_assets` 转换函数 AST 相同，并核对全部原 tex3ds 输出的尺寸、长度、SHA 和 CRC。只重绑布局 / 逻辑 IR 和生成器指纹，不重新生成或复制贴图；原有来源、纹理配方、转换逻辑或实际字节变化均拒绝保留。新增样式边距、缺失 / 错误类型的标题底板、旧 / 未知 capability 及收据保留的负向用例，未执行测试套件。

PSI 扩展将能力升为 3，格式 v2 / 规则 1 不变；旧能力 1 / 2 拒绝，新增文本、技能条件和窗口布局由同一独立包承载。

## 限制与验收

本切片仅支持当前单人 Ninten 与帽子，不能代表完整 Pause 或物品系统。其他命令、队员、装备、战斗物品使用与哮喘状态未实现。角色标签及部分底饰、Pause 信息板与音频滤波尚未接入；Pause 标题底板已按来源接入。自动尺寸控件采用已记录的有界单人适配，不宣称与 Godot 容器每个像素完全一致；英文零宽货币占位符按来源审查显示为空。

相关正常和负向用例保留在手动全面测试入口，本次未运行测试套件或 sanitizer。真实交叉构建及打包检查以对应候选 PR / Actions 为准；模拟器和 Old / New 3DS 的显示、输入、声音和存档验收仍待完成。

设备验收时分别检查正常五人启动资料与旧单人 LOAD、房屋和 Podunk 的打开与关闭、Mick 给粮前后打开菜单、四槽导航、帽子卸下与重新装备的预览 / 确认、取消保持原属性、战斗使用当前属性、Record / LOAD 保留同一帽子身份，以及英文 / 中文和 400×240 / 显式参考模式。还需检查剧情、战斗、仓库和存档菜单期间 START 不抢夺输入。
