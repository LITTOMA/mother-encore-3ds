# Podunk 通行与桥头进度

来源固定为 `7d9246600fffe518408f5830d4848635019005a3`。本分支仍在开发，下面分别记录已经实现的通行机制和阻止正常流程继续的依赖；不把完整地图绘制当作完整游戏已可玩。

## 已实现：跳跃提示区不再阻挡行走

原版 `Scripts/Main/Jump Area.gd` 的外圈 `Close` 只控制提示，内圈 `Inside` 参与 `_can_jump` 判定。暂停发生在确认后的 `_start_jump_process`，还要求 `eagle_feather`、启用状态、玩家 MOVE、没有暂停及空菜单栈。原移植把两层范围都编成接触即停止的开发边界，会把普通通路提前截断。

`content/podunk-field.json` 现在独立记录这些来源绑定与语义断言。编译器核对固定来源、羽毛旗标、内圈矩形以及当前场景的未同步 / 初始启用模式；未知模式仍拒绝。14 个跳跃区只生成内圈的确认边界。ENCMAP01 格式仍为 1，能力 2 增加 Confirm 记录，能力 1 保持读取；未知能力、降级后的新记录、能力声明与记录不一致均拒绝。

正常走近或经过不再停止。尚未持有羽毛时确认也不启动跳跃；满足已审查条件后的确认仍给出明确的未实现停止，可按 B 恢复。真正跳跃、射线筛选、箭头和羽毛获取尚未接入，不能把这个诊断边界声称为完整 JumpArea。

本地实际验证：Python 来源 / 容器 10 项通过；GCC ASan/UBSan 的 field_data 3,095 项和碰撞索引 220,251 项通过；Mick 使用真实固定 tex3ds 恢复缺失的本地生成收据后验证通过，受检 Mick 包未变。14 区域的检查使用明确的位置 / 旗标夹具；西侧道路检查也从人工道路检查点开始，不代表已经从家门自然走到那里。

## 仍须接通：桥头到镇区

只使用已支持条件的路线搜索仍无法从家门走到西侧道路；桥头的 `Podunk/cutscenes/bridge_fight` 是正常进度的实际阻挡。因此本分支尚不能声明已经扩大了从开局可达的镇区范围。

继续审查和实现：原版流浪狗的演员与场景内状态、桥头剧情、独立遭遇资源、bite / bash 及原版背景和音乐、战后 EXP / 金钱 / FleaBag 掉落及库存准入，再接 `pippismom_call`。不能用开场 Lamp / Doll 数值替代流浪狗，也不能跳过战斗直接设置 `beat_dog_bridge`。

所有真实构建、模拟器及原版对照结果将在实际执行后补充。当前没有桥头战斗、镇区自然到达或硬件通过声明。测试中生成的文件限定在本任务 build 目录；完整原始日志仍保留，后续清理对象文件和下载包时保留收据。


## 野外人物接入

`content/podunk-npcs.json` 按原场景顺序绑定 npc20（Pippi 的妈妈）和 npc41（桥头流浪狗）。`tools/field_npcs.py` 核对 npc.tscn 子节点几何、实例覆盖、脚本默认值和 4dir 动画，从固定上游生成两份独立 motion owner；没有复制 Mick 的对话、狗粮或地下室钥匙程序。

ENCMIK01 capability 4 是只含动作的资源：必须有非零 owner，程序 / 命令 / 文本表为空，物品与故事程序引用必须为空；未知 feature、版本和 RNG 保留字段拒绝。旧 capability 3 的 Mick 资源保留原字节。ENCMAP01 capability 3 增加带条件的 Actor 绘制记录，引用独立 field Room 的演员索引，并保留原 NPCS 的 YSort 顺序。ENCRSC01 capability 6 允许多份 FieldNpc 绑定，身份独立于单例 role ID。

两位人物使用原始 PNG、实际帧网格与动作：妈妈凝视玩家但不漫步；流浪狗漫步，空闲时也播放 Walk。每个活动人物的脚部碰撞随位置更新，运动查询只排除自己的脚部。故事取得 / 释放演员时交接位置，已隐藏人物立即退出显示和动态碰撞。原位暂停不会继续漫步。

目前此提交只接入两位人物的显示、移动与碰撞；桥头战斗、妈妈的呼喊和日常对话仍未接通，相关开发边界保留。Mick 的局部来源随机数账本被分别重放为独立 motion owner；这不是完整原场景共享 RNG 的等价实现，未移植人物的副作用仍是已知限制。不得据此声称已经能从正常入口进入镇中心。

资产由固定版本真实 tex3ds 转换，保留对应 receipt；未增加字体或第三方工具二进制。主机检查、交叉构建、模拟器和真机结果分别记录，未测层次不推断通过。
