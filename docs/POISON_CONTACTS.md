# 原毒液区域的自动玩家接触

原版毒液回调已有角色伤害消费者，但仍需调用者手动指定区域进入／退出。这个候选依据实际玩家形状与毒区几何采样接触，自动交付原回调，连接现有持续伤害、状态、跑步声和阴影消费者。正式墓穴场景尚未批准这些能力，因此不扩大当前游戏可玩范围。

固定原作仍为 `7d9246600fffe518408f5830d4848635019005a3`。独立 `ENCPCN01` format1／capability1 资源为8,088字节，保存原玩家平移后的八顶点碰撞形状、11个毒区的22份原引擎凸分解，以及嵌套的原毒液资源。生成器逐项核对来源顶点、覆盖面积、稳定区域身份和嵌套来源；没有在C++保存地图内容或调参，没有修改既有包、规则或存档格式。来源、许可和实际映射在 `content/catacombs-poison-contacts.json` 及对应审查记录。

共享核心在节点处理前发布上一物理样本的区域事件，在移动完成后采样本轮几何。双向layer／mask匹配、enabled与monitoring决定有效接触。原版暂停进入会消费该事件，恢复后持续停留不会补发；必须离开再进入。Other身体保留物理对但不调用玩家效果，Party和未知身体身份明确拒绝。采样失败、无效输出、错误角色／代次、缺少声音／阴影消费者等不会提交一半的角色或接触状态。当前仅审查单次区域转换；同时跨出和进入两个区域会明确拒绝，不能把未审查的宽相位顺序任意排序或丢弃。

几何采用既有稳定凸形状查询所用的包含边界SAT，仅支持平移。它不复制原物理服务器的接触边距、任意变换、同帧回调延迟或运动求解器；这几个差异仍属于正式接线前的边界。

最新局部GCC ASan／UBSan保留正常泄漏检查，24,497项通过，包括105个原状态、逐字RNG／状态／事件、全部资源截断和版本／能力／目录错误、来源与几何不匹配、角色存储保持、旧代次、重入／结束顺序、失败后重试、同时区域转换和退役边界。实际重新编译接触与受影响伤害模块，链接逐文件核验未变的117模块归档；不是完整核心重编译。
