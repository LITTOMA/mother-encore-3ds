# 毒液喷口时序候选

固定原作 `7d9246600fffe518408f5830d4848635019005a3` 的 `Poison Geyser.gd` 与 `poison geyser.tscn` 已映射为独立 `ENCGYS01` 格式1／能力1。1,552字节资源保留两个动画、48个属性节点、三个方法／声音节点、三个原MP3的实际原引擎长度，以及原Sprite、旋转矩形、可见区域和Audio2D参数。所有游戏绑定与数值来自受检资源，C++只负责加载与执行；没有更改原包、正式资源目录、游戏存档或旧场景能力。

`GeyserTimeline` 保留二进制32位动画时间、有效零步长属性采样、非循环末端、普通属性与延后方法的不同阶段。跨过多个声音节点时只发出最后一个声音的 set_stream／play；带结尾裁切的声音仅在没有新节点的后续更新、经过时间严格大于缓存长度时 stop。这个缓存不是原声音节点的 playing 状态，不能替代自然解码完成。

玩家暂停信号分别修改动画 active 和声音 stream_paused；显式 manual advance 仍然执行。UI每次处理独立写入原版0／-80 dB。延后 rumble 在真正执行时检查当前可见性、UI和全局同名声音；已经 queue_free 的实例在实际删除前仍可处理该回调。场景／实例归属、退役、未知版本／能力／节点类型、字符串别名、非有限数和不支持的多音轨目标在提交前拒绝。

## 已完成的验证

两次真实Godot 3.6.2运行各11组、451个观察完全一致，结果SHA为 `bead4b5c2947bab5e2867dc19b65911204d2fe124f38cd7e569dfc181be08662`。实际原场景、PNG、三个MP3、原导入参数与声音总线在隔离副本运行；Audio2D观察脚本记录调用并转发原生方法，全局声音使用原版add／play／get方法及真实节点。观察适配、输入指纹、全部原始日志和精确引擎源码／许可证在 `reports/geyser-timeline/`。手动动画模式用于确定地推进，不能据此声称自动游戏时钟已对齐。

原引擎包括细步长、长帧、零步长、暂停后显式推进、结束同帧回调、离屏、延后执行前切换三种UI状态，以及同名音效已播放／空闲情况。C++逐项核对状态与播放命令，最新10,000项GCC ASan＋UBSan检查通过，开启正常泄漏检查；11项Python检查通过，覆盖损坏、未知版本／操作及来源／观察凭据。实际新模块链接字节未变的117份核心归档，不称为本地重新编译全部120份核心。Windows配置只发现336项CTest，没有运行完整矩阵。

早期运行失败也保留：SceneTree脚本过早解析autoload、未发出的观察信号，以及JSON展示精度使观察用例说明无法按原始双精度数字逐字比较。最终用输入哈希、逐步二进制delta和不含展示浮点的用例身份核对，未更改动画期望。第一次C++负向用例原本写出了合法路径片段，已改为实际绝对／跳级路径；生产代码没有为此放宽检查。

两轮稳定结果和最新检查通过后，七个临时原引擎项目及被替代的首个测试程序已按路径、所有者、长度和SHA审计清理，共8,192,181字节。原始日志、适配源和最新程序保留。
