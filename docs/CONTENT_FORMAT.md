# 内容与存档格式 v1

此格式目前只用于原创M0 fixture。真实游戏IR扩展时需要明确升级，不直接把未知Godot资源装进当前字段。
所有整数小端。不要用C++结构体内存布局直接读写；实现逐字段读写，避免ARM对齐和编译器padding差异。

## 内容文件 ENCPAK01

64字节头，随后是payload。最大文件4MiB（M0防御性限制，不是全游戏资源预算）。

| 偏移 | 类型 | 字段 |
|---:|---|---|
| 0 | char[8] | `ENCPAK01` |
| 8 | u32 | 格式版本，目前1 |
| 12 | u32 | 规则版本，目前1，只代表fixture规则 |
| 16 | u32 | payload字节数 |
| 20 | u32 | payload的CRC32 |
| 24 | u32 | 所需能力mask，目前编译器要求15 |
| 28 | u32 | 内容族，目前`0x454e0001` |
| 32 | u32 | 字符串数量 |
| 36 | u32 | 地图数量 |
| 40 | u32 | 程序数量 |
| 44 | u32 | 敌人数量 |
| 48 | u32 | flag数量 |
| 52 | u32 | 起始地图下标（仅包内引用） |
| 56 | i32 | 初始像素x |
| 60 | i32 | 初始像素y |

payload依次为strings、maps、programs、enemies、flag IDs。文件不能有未声明的尾部字节。

字符串：u16 UTF-8字节数 +字节。最多1024条，每条最多1024字节，禁止NUL。
当前3DS文本采用设备系统字体；字符显示覆盖需实机验证，不能假定任意Unicode均支持。

地图：u32稳定ID、u32标题字符串下标、u16宽、u16高、u16对象数、u16保留0，
随后`宽×高`个u8图块（0可行走、1墙、2水/阻挡），再跟对象记录。
每格16×16逻辑像素；地图3..64格每轴，最多64张。对象最多128个/地图。

对象：u32稳定ID、u8类型、3字节保留0、i16 x、i16 y、u32程序下标、u32名称字符串下标。
类型0=guide、1=door、2=terminal、3=sign。这些仅是fixture展示/交互类型，不是完整Godot行为分类。

程序：u32稳定ID、u32指令数、指令数组。最多512个程序，每个最多2048条指令。
指令16字节：u8 opcode、3字节保留0、i32 a、i32 b、i32 c。

| opcode | 名称 | 操作数及行为 |
|---:|---|---|
| 0 | END | 结束当前程序 |
| 1 | SAY | a=文本索引；挂起直到确认/取消关闭 |
| 2 | SET_FLAG | a=flag下标，b=0/1 |
| 3 | IF_FLAG | a=flag下标，b=0/1；满足则PC=c |
| 4 | JUMP | PC=a，限制在本程序范围 |
| 5 | WAIT | a=tick数量，0..36000；让出当前tick，再等待a个tick |
| 6 | TELEPORT | a=地图下标，b=x，c=y；让出当前tick |
| 7 | BATTLE | a=测试敌人下标；挂起直到测试战斗结束 |

所有索引与传送落点在加载时验证。每tick最多执行64条同步指令，循环超限报错停止。
编译器要求最后有END，但不证明程序必然终止；运行时预算处理同步死循环。

敌人：u32稳定ID、u32名称索引、i32 hp/attack/defense/reward，共24字节。
flag表：u32稳定ID数组，最多32个。每个命名空间内部ID唯一；对象ID全地图唯一。

### 内容manifest与source map

编译器生成`build/content-manifest.json`：来源输入SHA256、编译器SHA256、产物SHA256、计数、能力和来源说明。
`build/story-source-map.json`将`programStableId:PC`映射回JSON pointer。
当前产物来源是fixture，所以`upstream_commit`为null；真实导出器上线后应写入已验证commit及依赖指纹。
文件CRC用于损坏检测；发布SHA256用于一致性核对；两者都不自动等同于来源认证。

## 存档 ENCSAV01

头与状态顺序：magic[8]，u32格式1，u32内容族，u32规则版本，u32地图稳定ID，
u32 x/y/hp/xp/rng/tick/flag_count，随后每个flag为u32稳定ID+u32值，最后u32前面全部字节的CRC32。
总长 `56 + 8*flag_count` 字节。

保存的是稳定ID，不是map或flag的数组下标。包内表重排不破坏身份。
新增flag默认false；移除保存过的flag/地图、规则或格式不匹配会明确要求迁移。
读取到临时State全部验证后再提交，失败不会部分覆盖当前游戏状态。

当前存档规则：只有World模式且VM不活动时能存/读，坐标必须在可走格，hp为1..30，rng不能0。
这些上限仅属于fixture，不应直接复用于真实游戏。
目前没有任意剧情中途保存、战斗中途保存或旧版本迁移器。
