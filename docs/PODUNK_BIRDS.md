# Podunk Birds source slice

All 54 `Scripts/misc/birds.gd` instances from the pinned complete Podunk scene are compiled into independent `data/podunk.encbirds`. JSON is build-time source IR and conversion receipts; no JSON runtime loader is added. The three original PNG atlases become `graphics/objects/birds/{0,1,2}.t3x` with genuine tex3ds RGBA8 conversion and nearest sampling.

`FieldBirdData` checks source scene/pin identity, family/version/capability, CRC, IR proof, source closure, ordered instance IDs, independent native child IDs/Ready ordinals, track properties/update modes/key ranges, atlas bounds and proof hashes. Failed reload retains the old complete resource. The resource never admits the whole scene.

Initialize `FieldBirdRuntime` with the scene's ONE shared `SourceRandom` and persistent checked data/host. Create every actual source instance before Ready to install its four original source signals. Call `ready(id)` once in actual postorder Ready order. Each `_prepare` draws source skin via randi, seek via randf, facing via randi, speed via randi, in that exact order. `screen_enter` and `screen_exit` must come from the real native notifier host; both source handlers can redo `_prepare`. Do not manufacture proximity events: source Area layer4096/mask0/monitorable=false is preserved, including its actual lack of compatible bodies unless a separately admitted live source change occurs.

The native `AnimationPlayer` and `Timer` children are separate source idle entries. Dispatch `idle_leaf(child_id, delta, actual_can_process, actual_timer_paused)` in source process priority/tree order even while the bird script is hidden or process=false. The bird root dispatches `idle_process(root_id, delta, actual_can_process)` at its normal source idle entry. Reprepare does not reset timer, z-index, sprite offset or prior velocity. Timer stores double time-left and exposes the original float/max-zero comparison; its timeout is strictly below zero, not at zero. Hop offset uses the exact original native eased Vector2 tracks and six native clips; discrete key lookup uses Godot's approximate binary search and original endpoint rule. Source `anim_name == "hop" or "hop right"` remains always truthy. Reaching Idle end via zero-delta seek stops without emitting finished; a real advance into the end emits finished synchronously before the source callback selects hop.

Host callbacks are mandatory, with persistent ownership until exit-tree. `texture` receives the actual Sprite child ID. `animation_signal` receives the actual AnimationPlayer child ID, started/finished and typed clip role: the actual synchronous signal bus invokes the registered finished slot ONCE. `timer_timeout` emits the actual Timer child timeout; no invented timer handler is registered. Live source signal admission rejects unimplemented extra property/frame/texture/animation listeners, queues, blends and mutations. `publish` updates actual Sprite frame/offset/flip/texture, root transform/z/visibility, script process gate, Area and notifier geometry. `observe` audits actual ancestor mechanisms, native material, still-disabled body shape, zero cached platform/floor state, live parent transform, notifier onscreen and ancestor visibility. `canvas_color` is the inherited ancestor color excluding this bird root and Sprite; the runtime applies source root modulate and Sprite modulate/self-modulate. Root self-modulate does not propagate to the child Sprite.

The source KinematicBody has only a disabled CircleShape. Godot's native zero-active-shape `test_body_motion` branch returns the complete world displacement: this exact bounded case is implemented, including diagonal non-normalized speed and inverse current parent transform. Changed enabled collision or cached floor/platform state fails closed. This does not replace the general collision solver. Global player identity and the original comparison of LOCAL `body.position.x` come from the actual host; world-space guesses are rejected by design.

The GPU primitive consumes source Sprite frame/offset and local centered floor before transforming. Each destination vertex receives native pixel snapping, UV flip leaves source rectangle placement unchanged, and multiplicative tint uses Citro2D blend=0. SceneHost owns actual Canvas/YSort/depth order and effective ancestor lifetime/visibility. No CPU background rasterization or random/clock duplication lives in the renderer.

Actual validation: complete fixed official native export to IR; 130 source closure hashes checked; real three tex3ds conversions using a four-worker queue; generated 26,715-byte binary successfully loaded by independent checked format admission. Runtime/reader/manual source compile with host GCC and devkitARM `-Wall -Wextra -Werror`; genuine Citro2D/Citro3D renderer header compiles for ARM. First own compilation failed misleading indentation in two files, corrected in current source. Manual parser/lifecycle case source is compiled only, not executed; no tests/sanitizers were run. Complete 3DSX/CIA packaging and emulator/hardware behavior are owned by integration and remain outside this slice's evidence.

Clean-clone compile uses public IR/review/conversion receipts, immutable upstream inventory and actual tracked upstream source bytes, plus generated real atlas inputs if tex3ds is unavailable. It does not require the private 315MB native export or ignored reports. Fresh IR extraction explicitly requires the complete official native export; its SHA is retained in the public source IR without private absolute paths. Full Podunk Ready is still blocked by uncovered source families; this resource declares scene_admitted=false.
