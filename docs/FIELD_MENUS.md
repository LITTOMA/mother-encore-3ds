# START 菜单

本次范围是 START 的六项及其子菜单，运行在当前已接纳的单人 Ninten 流程上。它不扩大可游玩地图、角色等级或战斗规则。

| 入口 | 当前角色和内容下的行为 |
| --- | --- |
| Goods | 普通/关键道具切换、描述开关、装备/卸下、使用目标、结果确认、自动排序、手动交换位置、丢弃确认 |
| PSI | 按学习状态列出 Telepathy 和剧情获得的 Lifeup α；目标取消不扣 PP；确认后执行原效果与结果页 |
| Equip | 四装备槽、可用候选、None、UID 保留、属性预览及提交 |
| Status | 实时 HP/PP、等级、当前/下级经验阈值、五项战斗属性、四槽装备；Field/Battle/PSI 技能页及描述、费用 |
| Map | 持有地图才显示 Podunk；否则显示原版缺地图页面；原地图与标记、角色位置、滚动、快速滚动、标记开关、取消返回；MapPodunk 的 Use 进入同一查看器 |
| Options | 存档文本速度/菜单主题/按钮提示；主音量/BGM/SE；显示范围；按键重绑和重置确认；已接入语言；返回标题/退出确认 |

原版在单人队伍隐藏 Give，关键道具没有 Drop；CashCard、Basement Key、Diary、DogTreats 的源码 actions 为空，因此只提供排序。不存在同伴时不制造接收人或交换物品。这些条件来自原版 `ActionSelect.gd`。其他角色加入和未接纳物品/PSI 的执行仍属于后续游戏移植范围。

哮喘喷雾在健康角色上使用会显示原版失败文本并扣一次使用次数；这是 `Inventory.consume_item` 的原行为。当前游戏状态仍不接纳异常状态，菜单没有放宽这一边界。装备丢弃后重新计算属性并钳制 HP/PP；UID 与 RNG 不重建。取消目标、排序或丢弃不修改状态。

PC 的窗口分辨率、全屏、整数缩放与 VSync 适配为 3DS 的固定显示约束说明，以及 400×240 / 320×180 显示范围选择；选择后保留现场，不重置游戏。职员表在原版 OptionsUI 中属于 title-only，START 菜单不显示。

控件以实际重绑后的按键显示。方向键/摇杆导航与触屏确定沿用共享输入适配器；按键捕获用方向键左取消，交换已有绑定以保证确定、取消等操作仍可到达。音量改变直接更新混音，含区域 BGM，不重启音乐流。全局音量、显示与绑定写入独立的 `menus.encprefs`；语言沿用独立偏好文件；文本速度、主题、提示和描述开关进入原有会话保存，不自动覆盖游戏槽位。

`ENCFMN01` schema 1 / capability 1 / rules 1 保存菜单文案、物品动作和排序分数、技能筛选条件、布局、平台绑定与原版 RGBA 地图。加载器拒绝未知版本、动作、非法引用/尺寸、非有限数、重复绑定和尾随数据，失败保留先前对象。3DS 层只上传像素并绘制共享状态；字体继续使用已有、来源已审查的字体包。`FieldEquipment` capability 5 接纳六项命令，其他四项须有显式 host，不能隐式成功。`NativeSession` schema/capability 9 增加逐物品的丢弃/消耗政策和描述开关，ENCSNAP1 存档结构不变，旧资源按旧规则加载。资源目录 capability 6 要求新的 FieldMenus 角色。

来源固定在 `7d9246600fffe518408f5830d4848635019005a3`。提取、编译与暂存均通过 `tools/field_menus.py`，完整来源列表见 `reports/field-menus-source/source-review.json`。地图图像符合上游 LICENSE 中与本游戏相关的修改用途；保留原始许可，不视为本项目 MIT 代码许可。既有装备纹理通过原转换 AST、来源和字节指纹保持不变的复用程序重绑定，命名流程的游戏/UI 二进制也保持不变。

验证记录在本次 PR 中分别列出。主机检查、3DS 构建、打包、模拟器与真机不相互代替；真机未验证。
