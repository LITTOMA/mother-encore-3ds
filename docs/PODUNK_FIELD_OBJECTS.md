# Podunk field object consumers

The fixed source scene has 16 Presents, 3 DroppedItems, 10 OpenableDoors, 4 payphones, 22 Sparkles and 94 butterflies. Each family has an independent checked binary and real source behavior consumer. Source JSON is a build input; the console does not parse it.

FieldSceneHost capability 3 maps these families to exact stable IDs, Ready ordinals, scene/source hashes and actual child Prompt identities. Present/Dropped retain source hashes from their binary closure for live cross-pack admission. The shared Sparkles owner bridge delegates 19 child clocks to the real Present/Dropped owners, consuming each original shared RNG draw exactly once. The three standalone Sparkles retain their own clock. Borrowed animation listeners must be admitted before execution; new listeners are not ignored.

FlaggableObject area_left connections are registered per actual object before derived Ready. ItemHolder resets reset_when_leaving_region to false. Presents and DroppedItems keep actual inventory/UID/current-item/Room operations behind required typed endpoints. A missing endpoint rejects activation. OpenableDoor and payphone likewise require real collisions, inventory, prompts, audio and dialogue. Butterflies preserve original appearance/flight/timers; their source does not restore HP or PP.

CashBox and PhoneUnitsBox preserve their separate source timers and animated layout. Their GPU renderer uses original checked textures and EBMain.tres, including the original fallback order. A separate reviewed source-font group supplies its amount symbols and digits. Palette additions are admitted at a GPU-safe load boundary through the checked public API.

These consumers do not yet activate the complete Podunk scene: 151 unknown leaf instances and remaining source effects/programmes still block its full Ready boundary. The normal Mick/key route remains unfinished. Current shipping resource staging continues to include only content connected to House.

The integrated source-format jobs, seven runtime/data pairs, SceneHost/SceneData and GPU renderer headers compiled with the real devkitARM toolchain. A synchronized source overlay also produced genuine 3DSX and CIA packages. Clean-commit packages are recorded separately in the PR. No automated host/sanitizer test suite, emulator run, hardware run or visual/FPS validation was performed for this slice; manual positive/negative case sources remain available.
