# 钥匙计数图形准备

固定上游 `7d9246600fffe518408f5830d4848635019005a3`，本候选只补齐原版 KeyCount 的图标与 ASCII 数量文字绘制服务。正式墓穴、计数持久化、存档和 UI 创建仍待接线；它没有扩大当前可玩范围。

## 来源与资源

`content/catacombs-key-hud-graphics.json`审查完整 `Nodes/Ui/KeyCount.tscn`、`Scripts/UI/KeyNumber.gd`、BottleRocket 定义及四个字体文件、原图标与许可证，共九项来源。原许可允许本游戏相关 fork 使用素材；保留原条件与既有字体声明，不将素材重新许可为 MIT。

独立 `ENCKGFX1` format 1 / capability 1，当前909字节，包含受检的749字节计数状态、图标长度／CRC、已有 SAVE 布局资源的长度／CRC、局部位置和两种视口。通过原生成器制作真实图标T3X，候选只写入 `build/`；没有修改正式 RomFS、catalog、规则或游戏存档版本，也不复制字体文件／图集。

两次原引擎保留完整原场景、脚本、图标及四字体，观察者仅直接设置五种文字，未调用计数脚本方法。原生容器51×16，图标10×16；文字位于(14,2)，高度11；`x 1`宽18，其余四个样本宽19。七个字符 advance 与既有 SAVE 字体度量一致。原脚本的三个追加诊断属于此前状态对照，不能由本次无脚本调用的布局检查宣称消失。

320×180保留原坐标；400×240按视口差(80,60)平移 HUD，保留右／下边距，图标和字形仍为1:1。整数像素放置沿用移植平台策略，没有声称像素或字节与原版一致。

## 所有权与失败行为

共享核心加载独立资源，核对嵌套状态的完整受检字节；配置、文本、颜色与位置均来自资源。未知格式／能力／保留字段、非有限坐标、危险路径、坏 CRC、未审查视口或不同状态身份明确拒绝，失败加载不替换旧数据。

CTR 服务只拥有一张图标，从长度／CRC核验后的同一份字节导入；准备失败释放候选纹理。绘制不查文件、不导入纹理，也不创建字体图集。调用者仍须在 GPU 空闲的 UI 边界准备／退役。

文字借用已驻留的 `SaveMenuRenderer` BottleRocket。SAVE 数据成功加载后缓存布局资源长度／CRC，渲染器记录已加载身份和单调重载代次；数据被替换、释放、重新加载或字体对象不同，旧帧都被拒绝。该身份核对针对布局／字形描述资源及寿命，不把它称为对 GPU 字体像素的再次校验。真实3DS编译单元实例化实际字体适配器；主机提交检查使用明确的字体／Tex3DS／C2D替身。绘制队列失败返回错误，不承诺已提交GPU命令能够回滚。
