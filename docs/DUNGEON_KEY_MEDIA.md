`DungeonKeyMediaData` 根据现有时钟生成绘制请求和碰撞矩形。钥匙或祖先隐藏不自动禁用碰撞；拾取的延迟碰撞关闭由原方法状态驱动。门体与交互区域分别处理：门打开后解除门体阻挡，交互区域继续存在，已打开门的方法自行忽略重复交互。绘制保留父 TileMap、原节点顺序、帧矩形、居中、翻转和深度信息。正式渲染、物理投递与 UI 子树仍需单独接入。

`DungeonKeyAudioRouter` 仅把时钟的音频写入转换为声音请求，原方法的拾取通知不额外播放一次。三个钥匙和三个锁头保持独立声音节点。实际完成时，钥匙执行资源声明的原完成回调；没有脚本监听器的锁头仅清除原生音频占用，不合成删除或动画完成事件。场景代次、对象／资源归属、未知类型、容量、损坏与过期回调均拒绝；失败不发布部分加载或声音批次。未来平台服务仍须在提交前预留声音批次，并检查平台声音代次。
