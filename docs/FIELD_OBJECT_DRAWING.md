# 正式场景对象资源与绘制接线

本批将已审查的 Podunk DroppedItem 接入正式资源生成、场景拥有者和 3DS 绘制消费者。内容仍来自固定上游 `7d9246600fffe518408f5830d4848635019005a3`，没有新增拾取规则或发放 Shovel。树根命中、独立声音播放器、完整取铲回调和 Pippi 救援尚未接通；本批不扩大这些玩法的完成声明。

## 独立数据与兼容

| 资源 | 本批能力 | 新内容 |
|---|---|---|
| ENCFOB01 | format1 / capability3 | 既有 136 字节对象行、离线 Ready 结果及纹理字节数／CRC；头部 56、60 为纹理验证字段 |
| ENCMAP01 | capability6 | kind7 按原场景树／YSort 顺序引用稳定对象 ID |
| 资源目录 | capability13 | FieldObjects=49，独立绑定 ID 1032 |
| ENCLNK01 | recipe schema4 / capability5 | 第七段按场景关联对象资源，旧六段前缀不变 |

对象能力1的显式随机入口、能力2的离线 Ready 入口和旧地图／目录／链接读取均保留。能力3不得使用运行时随机入口，纹理不匹配、未知版本、无实际消费者的伴随资源及错误交叉引用均拒绝。规则、Session 二进制及游戏存档格式不变。三个正式 Room 的全部解码内容与变更前相同；Podunk Room 仅构建来源身份改变，仍是能力13，没有发布包含删除指令49的取铲节目。

`content/field-objects.json` 保存对象路径、来源、稳定 ID、画布尺寸和输出位置；`content/podunk-area.json` 使用已有受检 AreaRoom 编译器读取实际 Podunk 来源。`tools/field_objects_assets.py` 校验脚本、继承与实例覆盖、旗标域、SpriteFrames、几何及精确来源文件，经真实 tex3ds 生成图集和凭据。生成器加入原有资源依赖图，打包只在目录声明对象角色时收集该资源，不允许未知扩展名混入其他目录。

## 来源行为

原 DroppedItem 静态场景含 Error 图像，运行时 `_update_sprite` 实际加载 Shovel；正式专用图集使用原始 Shovel 和 Sparkles 图素，逐个矩形的 RGBA 裁切均核对原图。32×32 图集经真实 tex3ds 转换为 4,117 字节，独立对象元数据为 672 字节，许可与转换器指纹由原生成器记录，不分发工具二进制。

铲子位置为 `(1432,4664)`。源序列化闪光帧22被同一次离线场景 Ready 重放覆盖为6，场景结束随机状态为 `621950984495336987`；消费者检查其等于 Mick 元数据的初始随机状态，不再次抽取。绑定先建立隐藏对象，首次 idle 显示而不推进动画时钟；之后按既有 binary32 时钟播放。现场写入 `got_shovel` 不自动隐藏／删除对象；重新进场时才按原 Ready 规则抑制，并在场景发布前提交删除队列。

原静态形状半径9×8、layer4／mask0，玩家为 layer1／mask4353，因而不阻挡玩家。数据保留原形状与层，不能强行加入玩家碰撞表。对象的真实绘制和提示索引都受检；删除提交后不再绘制或呈现该提示。手动拾取、Tween／消失演出和拾取提示尚未开放，不能据图像可见推断已经实现。

场景候选只有在地图、Room、Mick Ready 归属、对象和实际纹理全部验证成功后才能发布；错误加载保留原资源拥有者。3DS 消费者再次检查实际纹理大小／CRC、单张图、尺寸和方向，再以最近邻过滤按原顺序绘制主图和闪光。所有真实位置、旗标、帧与数值来自独立资源，执行代码不含这批游戏内容表。

## 当前验证层次

实际 GCC9.4 ASan／UBSan 与泄漏检查通过：新场景生命周期41、实际纹理／裁切映射53、目录／链接／加载回滚60；旧绑定70、元数据187、生命周期3022、延迟删除95、完整取铲候选6784、旧地图3107、Area663、Props6787及场景资源38。场景与加载负向夹具中的小型纹理明确为合成数据，不作为 GPU 纹理使用；53项实际图集检查使用真实转换产物。旧地图由原生成器显式禁用对象绑定重新生成，与迁移前文件逐字相同，旧行为检查继续使用它。

来源／编解码／资源链接39项、目录布局8项、资源依赖图与源文件表7项 Python 检查通过，完整方法收集为1233项（聚合868＋独立365）。Windows 仅完成 CMake 配置与方法收集，不能算 Windows C++ 构建。376项源资源核对通过。真实全量构建、GPU／模拟器及真机结果另行记录；本段尚不声明这些层次通过。

原始失败同样保留：旧测试从地图路径推导 Mick 路径，在新夹具目录下找不到文件，错误输出又持有已失效的 `c_str()`，ASan 报告发生在测试诊断；改为独立 Mick 参数和字符串引用后，故意缺文件会清楚失败且没有消毒器错误。Props 旧行为测试原先错误使用没有对象拥有者的新地图，现使用逐字相同的旧地图夹具。首次打包拒绝未分类的 `.encobjects`，加入精确目录规则和负向检查后通过，没有放宽未知文件准入。

本地 tex3ds 首次重写旧地图纹理时遇到 WSL 用户不能写 root 所有的旧文件；只调整被忽略的本地调用适配器，让同一已固定转换器写入私有临时目录，成功后由 Windows 写入精确结果并自动清理。未修改发布工具或上游。首个地图错误日志被后续调用覆盖，只保留了驱动返回值和当时工具输出的事实记录，不能宣称该份原始 stderr 文件仍在。
