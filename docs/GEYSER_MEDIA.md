# 喷泉自动时钟与声音服务候选

固定原作为 `7d9246600fffe518408f5830d4848635019005a3`，原引擎为官方 Godot 3.6.2。此候选延续 [喷口时序](GEYSER_TIMELINE.md)，补齐自动时钟对照、原版三段声音的独立媒体和生产音频服务。**正式墓穴、喷口生成器、Character 伤害与 GPU 尚未接线，不能据此宣称这段游戏已可玩。**

## 来源与数据

`content/catacombs-geyser-media.json` 引用受检时序与毒液资源配方，记录原素材许可核对和独立输出。`tools/catacombs_geyser_media.py` 同时核验前项保留的官方引擎源码和许可证实际字节，再使用受检 FFmpeg 转换原版 splash、blast、rumble。三份 44,100 Hz 双声道 PCM 共 1,645,056 字节；没有从开发者环境复制声音、字体、DSP 固件或工具二进制到发行资源。

独立 `ENCGMD01` format 1／capability 1 容器为 2,392 字节，嵌套原 `ENCGYS01` 时序和 `ENCAUD01` 声音库，通过稳定 ID 与来源 SHA 逐项绑定。元数据 SHA 为 `7a8074055ccb2f1d52aabad5ffd1df7b9636507d64d2230e3213cfa609944b87`。128 个逻辑声音是资源中明确的移植预算，不是“每个原版喷口最多一个实例”的推断。没有改动正式 RomFS、目录能力、既有存档或旧声音库。

原时序记录原生 MP3 长度，用于源 AnimationPlayer 的音轨结束偏移；PCM 的自然播放结束则独立依赖实际输出消费，二者不能混用。

## 原版行为核对

`tools/run_geyser_idle_reference.py` 在隔离工程中执行原 Geyser 脚本、自动 AnimationPlayer、真实延后调用及普通 AudioStreamPlayer 创建。观察器在源处理之后读取状态，再按预定输入触发玩家暂停、场景树暂停、可见性与战斗／剧情／失败 UI；没有手动推进动画或修改原版脚本。

两次各 224 帧和八个命名声音生命周期状态完全一致，结果 SHA 为 `c96ef392424310de479ea1952416227eba8df132e64189c2ba2f99fd542839f4`。原始日志、输入适配器和输出在 `reports/geyser-media/native-1`、`native-2`。前两次观察器提前停用造成超时；三至六次为较早观察范围，全部保留在 `preliminary`，没有视为最终验收。

原版存在容易误判的顺序：已存在声音节点在场景树暂停时会暂停；在已暂停树中刚创建的普通声音节点不会补收旧通知。玩家暂停和树通知也是顺序赋值，不能合并成一个布尔掩码。共享核心已按这些实际观察处理。

## 播放与生命周期

`GeyserMixer` 只含共享执行机制。独立源对象保留声音身份、偏移、源暂停、UI 音量、空间增益、播放请求和自然结束。源 Audio2D 的平移视口距离衰减／左右声道公式来自已保留的官方引擎源码；未知缩放、变换和多视口尚未接入，调用者必须明确提供受支持的监听参数。

`GeyserAudioService` 在 3DS 平台层准备三段 PCM，分块读取与 CRC 期间继续报告加载进度、补给既有 BGM。正常播放不分配内存、不读取文件。128 个逻辑子声音和一个独立命名 rumble 共用一个受检 NDSP 输出租约，不为每个喷口占用一个硬件声道。喷口退役停止自己的声音；原版独立命名 rumble 可以继续跨场景播放。

输出使用三块各 512 帧双声道缓冲。只有 DSP 缓存刷新成功后才提交混音游标，刷新失败可原样重试；只有确认缓冲已消费后才确认自然结束。未知声音命令、资源绑定、来源、版本、所有权或容量均明确拒绝，不部分提交。

本移植不声称与 Godot 解码器／混音器逐采样相同。原生 128 帧淡入淡出斜坡仍未复现；已排队的控制变化最多有 1,536 个输出帧延迟，另有设备延迟。当前原版对照使用 Dummy 输出，没有可听性或空间 DSP 实测结论。
