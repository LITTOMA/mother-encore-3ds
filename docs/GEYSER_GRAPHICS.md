# 喷泉图像与生产绘制候选

此候选延续 [喷泉声音服务](GEYSER_MEDIA.md)，固定原作 `7d9246600fffe518408f5830d4848635019005a3`，把原 Sprite 的 32 帧、局部矩形及绘制生命周期接入独立资源和生产绘制器。**正式墓穴、生成器、Character、物理与场景绘制顺序仍待接入；转换和图形接口替身不等于实际 GPU 验证或新增可玩范围。**

## 来源与资源

原图 `Graphics/Objects/Catacombs/Poison Geyser.png` 为 640×50，32 格各 20×50，不裁去透明边界。配方 `content/catacombs-geyser-graphics.json` 引用既有受检时序；转换器核对原 PNG、导入配置、项目像素吸附设置、已归档的官方 Sprite 引擎源码及许可证。原图逐格 RGBA 指纹留在转换记录，未声称它与 Godot 导入后的透明边缘处理逐像素相同。

独立 `ENCGFX01` format 1／capability 1 元数据为 2,772 字节，包含实际纹理长度／CRC、帧矩形和同一份 `ENCGYS01` 时序。真实 tex3ds 已产生 262,165 字节 T3X，SHA 为 `4ea2695cd126bcf32d8f4213c5ded1c87832c67f2934192bc1ae8c4c4ea34669`；转换输入和源声明经过核对。没有修改正式 RomFS、目录角色、原声音库或存档版本。

声音和图像可以分别持有经过相同校验的时序。新增 `same_content` 比较完整已校验时序字节，保留原 `same_owner` 对实际演员／混音器的严格所有权要求；没有把两个不同实例当成同一个演员。旧时序格式和执行行为不变。

## 原版观察

`tools/run_geyser_graphics_reference.py` 在隔离的官方 Godot 3.6.2 工程中加载原 Geyser、图像及导入配置。观察器暂停原动画后枚举实际 Sprite 帧，读取原 `get_rect`、`frame_coords` 与全局变换；另检查三个明确位置。源像素吸附设置启用，未运行或伪装完整角色伤害。

两次各 32 帧／三个位置的结果一致，SHA 为 `70abdc951031c437386def461877220221c8f95b54f450b578d9bba2681f16a0`。原始日志、输入和适配器保留在 `reports/geyser-graphics/native-1`、`native-2`。

第一次校验把恒等矩阵中的零假设成正零，实际 Node2D 输出负零。原始输出保留在 `preliminary-1`；校验器只在矩阵零分量接受 IEEE 等价的正／负零，非零、NaN、错误位置和错误输入仍拒绝。没有改动原版、原观察或期望坐标来消除差异。

原局部矩形为 `(-11,-56,20,50)`，再加 Sprite 的 `(0,16)`。生成器已提供实际根位置，绘制器不重复叠加预制体的 `(0,-8)`；该位置下左上角应为 `(-11,-48)`。相机偏移单独扣除。仅支持已审查的源 Sprite 变换轮廓，完整 CanvasItem／场景层次、遮挡和排序尚未实现。

## 绘制和实际检查

`GeyserRenderer` 在 GPU 空闲边界从一次长度／CRC 校验后的字节缓冲导入纹理，核验子纹理、尺寸、方向和 UV 范围。帧裁切以实际子纹理 UV 为基准，支持有边距的纹理；正常绘制不读取文件。场景代次、帧令牌、演员地址／实例、时序、根位置、相机和可见性必须仍匹配，拒绝重复提交和已退役演员。

- GCC 9.4 ASan＋UBSan、正常泄漏检查：最新两组各 3,473 项通过，一组使用明确假纹理，另一组使用真实转换的 T3X 字节；图形 API 均是明确替身，不包含解码器／GPU／像素结论。
- 共享时序新增字节身份后，相关旧回归重新通过：时序 10,000、自动时钟 7,208、媒体／混音 281,637、生产音频 2,938 项，均开启正常泄漏检查。使用当前变动模块与核对未变的 117 份核心归档，未冒充完整重新编译。
- Python 11 项通过，覆盖逐字截断、版本／能力／来源／目录、保留域、帧身份／尺寸、未知字段、引擎来源／许可证、原观察协议和缓存损坏。
- Windows 仅发现 342 项 CTest；此步骤没有执行主机或 SDK 检查。

首轮两个绘制测试误在离散键的精确终点要求新帧，已按先前审查且由原引擎验证的 `[from,to)` 区间改为键后一个可表示时刻取样。退役前也明确清空源延后／声音命令；未改生产时钟或原轨迹。失败源码、日志和修正后的执行均保留。已核验清理 44,607,253 字节临时工程、失败 scratch 和旧／重复程序。
