# 房屋战后调查与家人后续对话

固定来源：Mother: Encore `7d9246600fffe518408f5830d4848635019005a3`。本切片从现有正常房屋入口接入，保留既有开场、战斗、电话和保存身份。

## 可玩范围

- 调查公告板、老照片、电吉他、NES、楼上电视、楼下电视和 Mimmie 的玩具箱，使用原版文本及英文／简体中文绑定。
- 保留调查区域的继承碰撞、实例缩放、玩家朝向约束、提示偏移和有序旗标覆盖。闹鬼阶段使用原版“现在不是时候”对话；玩偶胜利后的调查文本按原版覆盖顺序选择。
- 爸爸电话后的 Carol 和 Mimmie 钥匙提示，以及设置询问旗标之后的再次对话。旗标写入由已受检 Room 程序执行；不是把带副作用的 YAML 当成纯文本。
- 床头抽屉完整的原版条件对话：先显示调查文本并等玩家确认，再检查已取得旗标和背包空间；首次成功赠予哮喘喷雾，随后显示取得文本、播放取得音效并写入旗标。重复调查和满背包分别走原版分支。
- 调查与 NPC、电话、门共用最近射线目标选择。未支持的最近对象仍遮挡后面的对象。调查没有原版阅读身份写入，不制造 NPC 已读记录。

## 数据与消费者

`content/native-house-inspections.json` 为来源 IR；`tools/house_inspection.py` 编译 `data/opening.encinspect`（ENCHIN01）。该资源只持有调查几何、绑定和条件，文本由追加链接进入既有 `.enchouse`，不重复字体或图像。

HouseInspectionData 检查版本、能力、目录边界、校验和、身份、引用及数值。HouseRuntime 绑定时检查来源、旗标注册和 House 对话索引／路径；普通启动、New Game 和 LOAD 都绑定同一资源。3DS 从受检资源目录加载该二进制，不读取 JSON。提示格式能力 2 增加调查对象，继续接受已有能力 1 的解析路径；存档格式、游戏规则和既有稳定身份保持不变。

抽屉另由 `content/native-drawer-program.json` 编译为 `data/opening.encdrawer`（ENCDRP01，格式／能力／规则 1）。独立指令保留背包条件、赠予、文本确认、音效和旗标顺序；消费者在执行前检查全部文本、物品、旗标和音效引用。物品 UID 由既有共享来源随机流和 UID 注册表产生，满背包分支不生成 UID；失败的库存追加不提交部分物品状态。

新增原版文本使 House 达到 129 段、66 个对话记录，超过旧格式的 128 段／64 对话上限。因此 House 独立资源格式／能力／规则升至 7，上限为 256 段／128 对话；token 上限仍为 256。加载器保留格式 4–6 的原有能力和容量限制，未知格式明确拒绝。Room 与存档格式、默认值和既有身份保持不变。

Session 资源格式／能力 4 追加来源派生的物品获取策略，只允许原始背包前缀之后出现受检的未装备赠予物品，并检查剂量、数量和取得旗标。保存与 LOAD 保留实际 UID；格式 1–3 仍按旧库存范围受检加载。资源格式更新不扩大存档编码格式。

## 明确边界

床头抽屉的条件、赠予及重复对话已接入，闹鬼阶段仍按有序覆盖选择普通对话。取得与保存哮喘喷雾不代表物品使用或哮喘治疗已经实现。Items 详情中的原版富文本描述仍有未支持能力，不能把它当作完整物品菜单验收。Minnie 的储物选择需要实际仓库消费者，仍不支持。非空调查出现／消失旗标涉及原版 Ready 和 flags_updated 删除顺序，本格式绑定明确拒绝。Podunk 和全游戏物品／菜单未因此完成。

## 验证与待办

新增格式和交互负向用例保留在手动全面测试入口。日常不运行主机测试或 sanitizer；资源编译执行必要的来源与格式准入，设备构建和打包结果由对应候选 Actions 记录。真实显示、输入、声音、真机和模拟器运行仍需分别验收。

修复用户报告的开场过场读取加载动画闪现：Introduction 活跃期间，加载回调保留最后提交的剧情画面，不绘制加载动画；资源校验、错误处理和 NDSP 队列补给继续执行。涵盖首次音频读取和切换房屋时的嵌套加载。真实过场显示仍待设备验收；同步读取本身的停顿尚未因此消除。
